# ⚔️ Relic Swarm

> **A relentless 2D horde survival roguelite with real-time build pivoting, arcane weapon fusions, and deep meta-progression.**

Inspired by genre pioneers like *Vampire Survivors*, **Relic Swarm** drops you into an omnidirectional gothic arena against hundreds of swarming monsters. Cast automated spells, gather arcane relics, crack open boss chests, and dynamically **sell equipped gear mid-run** to refund gold and adapt your build on the fly.

## 🌟 Key Features

- **Fluid Horde Combat**: High-density swarms rendered at a fixed 60 FPS with damage-scaled screen shake, micro hit-stop freeze frames, and responsive crowd-clearing feedback.
- **Dynamic Arsenal Selling (Mid-Run Pivoting)**: Don't get trapped in a dead-end build. Open your inventory or draft modal at any time to sell weapons or passives for an instant **70% gold refund**, immediately freeing slots for fresh synergies.
- **4 Distinct Champions**: Choose from Arcanist Vael, Knight Commander Roland, Pyromancer Ignis, and Plague Alchemist Mortis — each featuring unique baseline stats, starting weapons, and passive affinities.
- **Weapons, Evolutions & Fusions**:
  - **7 Base Weapons**: Magic Missiles, Orbiting Daggers, Flame Blast, Thunder Strike, Radiant Aura, Venom Spores, and Glacial Shards.
  - **Level 5 + Level 5 Fusions**: Combine max-level weapons to form dual-aspect super-weapons (*Arcane Phantom Vortex*, *Cataclysmic Supernova*, *Plague Sanctuary*, *Shatterstorm*, *Frostbite Chakrams*).
  - **Awakened Evolutions**: Pair maxed weapons with matching passives in boss chests for legendary forms (*Chrono Missiles*, *Hellfire Nova*, *Mjolnir's Conduit*, *Solar Eclipse*, *Necrotic Blight*, *Phantom Storm*, *Absolute Zero*).
- **Persistent Sanctum Meta-Shop**: Bank earned gold across runs in your Sanctum Vault and permanently enhance your attributes (Health, Might, Movement Speed, Cooldown Haste, Magnet Radius, Greed, and Fate Rerolls).
- **Universal Controls**: Full support for Keyboard, Gamepad / Controllers, and Virtual Touch controls for mobile and handheld play.

## 🎮 Controls

| Action | Keyboard | Gamepad | Mobile / Touch |
| :--- | :--- | :--- | :--- |
| **Move** | `W` `A` `S` `D` or Arrow Keys | Left Analog Stick / D-Pad | Virtual Analog Joystick (Bottom-Left) |
| **Sprint** | `Shift` / `Ctrl` | `Button B` / `RT` / `LT` / `X` | Virtual Sprint Button (Bottom-Right) |
| **Confirm / Select** | `Enter` / `Space` | Button `A` (Button 0) | Tap Button / Card |
| **Cancel / Back** | `Escape` / `Backspace` | Button `B` (Button 1) | Tap Close / Back Button |
| **Toggle Inventory & Sell** | `Tab` / `I` | Button `Y` (Button 3) | Floating Sell Button (Bottom-Right) |
| **Pause Game** | `Escape` / `P` | **Button 9 ONLY** (`Options` / `Start`) | Top-Right Pause Button |
| **Sanctum Shop** | `S` / `X` | Button `X` (Button 2) / Button `Y` | Tap Sanctum Vault Card |
| **Draft Quick Pick** | `1`, `2`, `3`, `4` | D-Pad / Stick + Button `A` | Tap Upgrade Card |
| **Draft Reroll** | `R` | Button `Y` (Button 3) | Tap Reroll Button |

> **Note**: Gamepad pause is strictly mapped to the **Options / Start button (Button 9)**. Stick clicks (L3/R3) are disabled for pause so intense analog maneuvering never interrupts your run.

## 🔮 Weapons & Evolutions

Players have **4 Weapon Slots** and **4 Passive Slots**.

### Base Weapons (Max Level 5)
- **Magic Missile**: Rapid homing arcane bolts seeking nearest enemies.
- **Flame Blast**: Explosive plasma bolts creating lingering scorching fire pools.
- **Orbiting Daggers**: Steel razor blades continuously spinning around the hero.
- **Thunder Strike**: High-voltage vertical lightning bolts striking clustered foes.
- **Radiant Aura**: Sacred glowing ring dealing continuous ticking AOE damage.
- **Venom Spores**: Toxic cloud eruptions inflicting stacking Poison DoT.
- **Glacial Shards**: Piercing frost spikes inflicting movement slow.

### Legendary Weapon Fusions (Level 5 + Level 5)
- **Arcane Phantom Vortex**: *Magic Missile L5* + *Orbiting Daggers L5* $\to$ 8 astral blades firing rapid homing energy beams.
- **Cataclysmic Supernova**: *Flame Blast L5* + *Thunder Strike L5* $\to$ Screen-wide infernos combined with celestial lightning storms.
- **Plague Sanctuary**: *Radiant Aura L5* + *Venom Spores L5* $\to$ Massive aura slowing enemies by 40% and dealing 24 poison DPS.
- **Shatterstorm**: *Glacial Shards L5* + *Thunder Strike L5* $\to$ Piercing ice lances freezing targets, followed by lightning shattering slowed/frozen foes.
- **Frostbite Chakrams**: *Glacial Shards L5* + *Orbiting Daggers L5* $\to$ Expanding and contracting ring of 8 cryogenic chakrams trailing freezing slipstreams.

### Awakened Evolutions (Max Weapon + Matched Passive via Boss Chest)
- **Chrono Missiles**: *Magic Missile* + *Swift Boots* $\to$ Continuous stream of hyper-velocity laser bolts.
- **Hellfire Nova**: *Flame Blast* + *Might Talisman* $\to$ Arena-wide cascading supernovae.
- **Mjolnir's Conduit**: *Thunder Strike* + *Swift Boots* $\to$ Lightning strikes drop electrified conduit pylons arcing continuous high-voltage laser beams.
- **Solar Eclipse**: *Radiant Aura* + *Vitality Charm* $\to$ Pulsing corona aura unleashing a gravitational shockwave repelling enemies and vacuuming XP.
- **Necrotic Blight**: *Venom Spores* + *Toxic Vial* $\to$ Massive corrosive spores; afflicted enemies that die explode into homing plague beetles.
- **Phantom Storm**: *Orbiting Daggers* + *Might Talisman* $\to$ 8 ethereal hyper-speed scythes.
- **Absolute Zero**: *Glacial Shards* + *Frost Amulet* $\to$ Cryogenic storms freezing and shattering enemies.

## 🏛️ Sanctum Meta-Shop

Gold collected from defeated foes and chests is banked into your permanent vault upon run conclusion:

- **Stamina Infusion**: +10% Max Health per rank (Max 5)
- **Might of the Sanctum**: +6% Global Damage per rank (Max 5)
- **Haste Footwork**: +5% Move Speed & Sprint Recovery per rank (Max 5)
- **Arcane Flow (CDR)**: +4% Cooldown Reduction per rank (Max 5)
- **Aetheric Magnetism**: +15% Gem & Gold Magnet Radius per rank (Max 5)
- **Golden Fortune**: +12% Gold Drop Value per rank (Max 5)
- **Fate Rerolls**: +1 Free Draft Reroll per run (Max 3)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm`

### Installation
```bash
# Clone the repository
git clone https://github.com/your-username/relicswarm.git
cd relicswarm

# Install dependencies
npm install
```

### Running Locally
```bash
# Start Vite development server with Hot Module Replacement (HMR)
npm run dev
```
Open your browser and navigate to `http://localhost:5173/`.

### Production Build
```bash
# Type check and build production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🛠️ Tech Stack

- **UI & Runtime**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) via `@tailwindcss/vite`
- **Language**: [TypeScript](https://www.typescriptlang.org/) (ES2022)
- **Bundler**: [Vite 8](https://vitejs.dev/)
- **Graphics & Engine**: HTML5 Canvas 2D with a 60 FPS fixed-timestep simulation stepper
- **Audio Engine**: Web Audio API synthesis + HTMLAudioElement BGM
- **Icons**: [`lucide-react`](https://lucide.dev/)
